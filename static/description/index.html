Centralize & Streamline Approvals in Odoo 18

The Universal Approval module is an enterprise-grade document validation engine. Instead of hardcoding approval workflows into every single model (Quotes, Bills, Job Cards), it unifies the entire workflow into a single, comprehensive backend. With seamless standard integrations, users can instantly request, approve, or reject documents directly from their respective forms.

Core Features

✅ Seamless Native Integration

Natively adds action buttons ('Submit for Approval', 'Approve', 'Reject') to Sales Orders, Accounting Moves, and Repair Orders right out of the box.

🔗 Universal Polymorphism

Backed by a robust res_model / res_id architecture, it functions effortlessly across any custom or standard Odoo model, not just sales or invoices.

🛡️ Centralized Dashboard

Allows administrators to see all pending approvals across the entire company in one unified list (Approvals -> Requests) regardless of model.

📝 Justified Rejections

Comes with a built-in Rejection Wizard, forcing approvers to provide a specific documented reason when blocking a workflow.

Developed to empower seamless Odoo workflows. Beautifully unified.
